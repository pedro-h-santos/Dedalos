# Projeto Raycasting Dédalo 
Estudo sobre raycasting usando linguagem C, no desenvolvimento de um jogo de exploração em masmorras, no estilo de jogos como DOOM e WOLFENSTEIN 3D.
## Modo de Uso
clone ou baixe o repositório para se computador, único requisito é ter gcc intalado em sua máquina, os arquivos "include" e  "lib", são bibliotecas do raylib, que ajudam na redenrização do pseudo 3D.
